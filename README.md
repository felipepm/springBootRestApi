# Spring Boot REST API

A production-ready REST API built with Spring Boot following modern backend development practices.

This project demonstrates how to build secure, maintainable, and scalable REST services using Spring Boot, JWT authentication, Swagger documentation, and JPA persistence.

---

## Features

- RESTful API
- JWT Authentication
- Spring Security
- Swagger / OpenAPI
- Spring Data JPA
- H2 Database
- Maven
- Exception Handling
- Layered Architecture

---

## Tech Stack

- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- JWT
- Swagger
- Maven
- H2 Database
